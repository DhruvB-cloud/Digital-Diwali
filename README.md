# Diwali Dhamaka 🪔

Celebrate Diwali digitally — no smoke, no noise complaints.

Open `index.html` in a browser (no build step).

- Pick a firecracker (Anar, Rocket, Atom Bomb, Chakri, Ladi) from the bottom row.
- It moves to the bottom centre and your cursor becomes a sparkler on a stick.
- Touch the sparkler tip to the fuse to light it — light and sound follow.
- Top-right shows the live AQI for your location (Open-Meteo; falls back to Delhi if location is denied).
  Every burst raises the AQI and makes the sky hazier and blurrier.
